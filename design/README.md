# Doondo Design System Package

## Files

-   `design.md` --- global product-wide design rules and alignment
    system.
-   `theme.md` --- System / Light / Dark theme architecture and tokens.
-   `layout.md` --- detailed spacing, grid, safe-area and alignment
    rules.
-   `components.md` --- reusable component rules.

## How to use with Claude

Give Claude the whole `design` folder and say:

> Read all files in the Doondo design system folder before changing or
> creating UI. The design system is global and applies to every screen.
> Use the supplied screenshots only as visual references. Keep
> alignment, spacing, typography, components and navigation consistent.
> Support System, Light and Dark themes through semantic design tokens.

## Important

Do not create a separate visual style for each screen.

The screen can have different content and layout, but the product should
always look like one app.
